# 15 — Window/Process Scanning (сканирование окон и процессов)

## Где (файл + метод/адрес)
- Сборка: RustSecure.Core.dll
- Файл: `LoggersStfld/BlendFrameUpdates.cs`
- Строки: [752280724] `cheat engine`, [752280727] `cheatengine`
- Обфускация: Agile.NET

## Как работает

### Перечисление окон
Использует `EnumWindows` / `EnumWindowsProc` для перебора всех окон в системе.

Для каждого окна:
1. `GetWindowText` — получение заголовка окна
2. `GetClassName` — получение класса окна
3. `GetWindowThreadProcessId` — получение PID владельца
4. Имя процесса по PID

### Белый список
Метод `IsWhitelisted(processName, className)` — белый список процессов, которые не вызывают срабатывание.

## Как обойти

### Вариант A — Патч EnumWindows (рекомендуется)
Заменить вызов `EnumWindows` на:
```
ldc.i4.1    // true (успех, но без перечисления)
ret
```
Callback никогда не будет вызван, окна не просканированы.

### Вариант B — Патч IsWhitelisted()
Заменить тело `IsWhitelisted()` на:
```
ldc.i4.1    // true — всё в белом списке
ret
```
IL-байты: `17 2A`. Все процессы будут пропущены.

### Вариант C — Удаление строк из чёрного списка
Найти массив/список строк (`cheat engine`, `ida`, `dnspy` и т.д.) и заменить каждую на пустую строку `""`. Сравнение с именем окна/процесса не совпадёт.

### Вариант D — Патч callback-а EnumWindowsProc
В callback-методе сразу возвращать `true` (продолжить перечисление без обработки):
```
ldc.i4.1
ret
```
